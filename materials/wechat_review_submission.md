# 得胜村便民服务 小程序提审文案

## 1. 小程序名称

得胜村便民服务

## 2. 小程序简介

为村民提供通知查看、公开信息浏览、诉求提交、政务办件申请、志愿活动报名、办理结果查询等便民服务。

## 3. 核心功能说明

1. 村民可直接打开小程序浏览通知、公开信息和服务内容。
2. 当村民需要提交诉求、申请证明、报名活动或查看个人办理结果时，需要先完成登录登记。
3. 登录登记流程为：
   - 微信登录
   - 微信 `getPhoneNumber` 绑定手机号
   - 填写姓名和身份证号
   - 后端按“姓名 + 身份证号”与村民户籍白名单做校验
4. 校验成功后，当前微信账号即可办理业务；若姓名和身份证号不匹配，则提示“身份信息校验失败”。
5. 若身份证号已被其他有效账号绑定，则提示“身份证号已被验证，请联系管理员处理”。
6. 本版本“开证明”已改为模板化办理：
   - 村民可申请关系证明等常见证明
   - 关系字段为固定选项，不允许村民自由输入
   - 村民可上传佐证图片作为附件
7. 村干部在独立 Web 后台审核证明申请：
   - 选择“情况属实”后，系统会生成加盖电子章的电子证明
   - 选择“驳回申请”后，村民端会显示驳回结果和说明

## 4. 信息采集与使用说明

小程序会采集并使用以下信息：

1. 微信身份标识：用于登录和用户识别。
2. 微信侧手机号：用于村民联系方式绑定。
3. 姓名和身份证号：用于基础实名登记和村民身份校验。
4. 证明申请相关信息：用于生成证明模板内容，例如关系证明中的双方姓名、身份证号、关系类型。
5. 业务图片：用于诉求、证明申请和其他办件附件上传。
6. 办理结果文件：用于村民查看电子证明和办理结果。

说明：

- 身份证号不在前端做名单比对。
- 前端不保存户籍白名单、校验密钥或本地加密表。
- 后端基于户籍白名单完成“姓名 + 身份证号”校验。

## 5. 隐私说明建议表述

1. 收集手机号：用于账号绑定、联系村民、业务办理通知。
2. 收集姓名和身份证号：用于基础实名登记、村民身份核验、证明内容生成。
3. 收集证明申请相关信息：用于关系证明等模板化证明的内容生成与审核。
4. 收集业务图片：用于诉求提交、证明申请、附件佐证和业务留痕。
5. 生成和展示电子证明：用于村民查看办件结果与下载留存。
6. 上述信息仅用于村务便民服务、实名校验、业务处理、审计留痕，不用于无关用途。

## 6. 合法域名建议填写

当前提审阶段按以下方式处理：

1. 普通接口与图片上传优先走 `wx.cloud.callContainer`
2. 不再把 `sh.run.tcloudbase.com` 填入微信后台 `request/uploadFile` 合法域名
3. 如微信后台要求补充下载域名，仅补：
   - `https://cos.ap-shanghai.myqcloud.com`

说明：

- 小程序普通接口走 `wx.cloud.callContainer`
- 图片上传也改为通过 `wx.cloud.callContainer` 进入后端，不再依赖公网 `uploadFile` 域名
- 图片展示与下载优先使用 COS 签名地址，因此建议加入 COS 下载域名
- 当前提审阶段仍使用云托管提供的运行环境；`api.example.invalid` 待备案完成后再切换

## 7. 审核备注模板

审核老师您好：

本小程序为村级便民服务小程序，主要面向本村村民提供通知公开、诉求提交、政务办件申请、志愿活动报名和结果查询服务。

村民无需登录即可浏览公开内容；提交诉求、申请办件、报名活动等操作时，需要先完成基础实名登记。基础实名登记流程为微信登录、微信手机号绑定、姓名与身份证号登记，后端再按村民户籍白名单进行“姓名 + 身份证号”校验。

本版本不接入短信验证码，不接入 FaceID，仅保留微信官方手机号能力与基础实名登记。

本版本“开证明”采用模板化办理。以关系证明为例，村民需填写双方基础身份信息、选择固定关系类型并上传佐证附件；村干部在独立 Web 后台审核后，会回传加盖电子章的电子证明，或填写驳回说明。该后台不在小程序内直接开放。

当前提审版本先使用腾讯云云托管默认公网域名进行接口访问与图片上传，待自定义域名备案完成后再切换，不影响本次审核体验。
